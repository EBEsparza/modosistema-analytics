Modo Sistema Analytics

Modo Sistema Analytics es una herramienta interna del canal de YouTube «Modo Sistema».

Lee, con permisos de solo lectura, las estadísticas del propio canal (vistas, retención, fuentes de tráfico e impresiones) mediante YouTube Data API y YouTube Analytics API, para elaborar reportes privados de rendimiento.

No publica, edita ni borra contenido, y no está disponible para otros usuarios.
