Política de privacidad

Modo Sistema Analytics · Última actualización: 27 de octubre de 2026

Qué es

Modo Sistema Analytics es una herramienta interna de uso personal del canal de YouTube «Modo Sistema». Solo la usa el dueño del canal con su propia cuenta de Google.

Qué datos se usan

Con los permisos de solo lectura youtube.readonly y yt-analytics.readonly, la herramienta lee datos del propio canal: lista y metadatos de videos, estadísticas públicas (vistas, me gusta, comentarios) y métricas de YouTube Analytics (tiempo de visualización, retención, fuentes de tráfico, impresiones y CTR).

Cómo se usan

Los datos se guardan únicamente en el equipo del dueño del canal para generar reportes privados de rendimiento. La herramienta no publica, edita ni borra contenido de YouTube.

Con quién se comparten

Con nadie. Los datos no se venden, no se transfieren a terceros y no se usan con fines publicitarios.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La herramienta también cumple las Condiciones del servicio de las API de YouTube y se rige por la Política de privacidad de Google.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Para borrar los datos guardados localmente, basta con eliminar la carpeta de datos de la herramienta.
